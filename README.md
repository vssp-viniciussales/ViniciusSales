## 🚀 Como publicar no GitHub Pages

1. Crie um repositório chamado `vssp` (ou qualquer nome)
2. Faça upload de todos os arquivos
3. Vá em **Settings → Pages**
4. Em **Source**, selecione `Deploy from a branch`
5. Branch: `main` · Folder: `/ (root)`
6. Clique **Save**
7. Aguarde ~2 minutos e acesse `https://SEU-USUARIO.github.io/vssp`

## ✏️ Como personalizar

### Trocar e-mail de contato
Em `index.html`, localize:
```html
<a href="mailto:contato@vssp.com.br" ...>
```
Substitua pelo seu e-mail real.

### Trocar link do Instagram
Localize `https://instagram.com/vssp.viniciussales` e substitua pelo seu handle correto.

### Adicionar domínio próprio
1. Compre um domínio (ex: `vssp.com.br`)
2. Em GitHub Pages Settings → Custom domain, adicione o domínio
3. Configure o DNS conforme as instruções do GitHub
